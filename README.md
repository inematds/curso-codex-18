# Codex: os 18 conceitos essenciais

Curso gratuito do [INEMA.CLUB](https://inema.club) para quem nunca usou o Codex: os 18 conceitos que transformam o agente da OpenAI num assistente que conhece o seu trabalho. Projetos, AGENTS.md, o ciclo do agente, /goal, local × nuvem, worktrees, a pasta .codex, modelos, esforço, permissões, skills, a pasta .agents, plugins, navegador, sites, subagentes, tarefas agendadas e modo de voz. Cada tópico tem uma ilustração.

**Abrir o curso:** https://inematds.github.io/curso-codex-18/

| Trilha | Módulos |
|---|---|
| 1 · Fundamentos | Projetos · AGENTS.md · O ciclo do agente · /goal |
| 2 · Ambientes | Local, nuvem e celular · Worktrees · A pasta .codex |
| 3 · Controle | Modelos · Esforço e modo rápido · Permissões · Skills · A pasta .agents · Plugins |
| 4 · Ferramentas e escala | Navegador · Sites · Subagentes · Tarefas agendadas · Modo de voz |

Formato `formato-curso-v2` (HTML + Tailwind CDN + JS, sem build). Progresso, dúvidas e notas ficam só no navegador.

Manutenção: edite `context/corpos/`, rode `python3 scripts/montar.py` e `python3 scripts/lint.py`.
